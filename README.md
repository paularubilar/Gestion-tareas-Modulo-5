Este proyecto consiste en una aplicación de gestión de tareas diseñada para fomentar la productividad consciente, integrando los principios fundamentales de Programación Orientada a Objetos (POO) y JavaScript ES6+. La aplicación permite crear, filtrar y persistir tareas de forma local mediante localStorage, ofreciendo una experiencia interactiva y dinámica a través de la manipulación del DOM, eventos asíncronos y el consumo de la API OpenWeather para visualizar el clima en tiempo real según la geolocalización del usuario.
